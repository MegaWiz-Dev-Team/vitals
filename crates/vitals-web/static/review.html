ตรวจ Vitals

เลือกก่อนว่าคุณตรวจในบทบาทไหน — คำถามจะเปลี่ยนตามบทบาท

อยากพูดมากกว่าพิมพ์: อัดเสียงส่งกลับมาทางเดิมที่ได้ลิงก์นี้มาได้เลยครับ (LINE หรืออีเมล) — ฟอร์มนี้รับไฟล์เสียงไม่ได้ จึงไม่ทำปุ่มอัปโหลดหลอกไว้ · จะกดตัวเลือกในข้อที่ตอบได้ก่อน แล้วอัดเสียงเฉพาะข้อที่อยากขยายความก็ได้

เก็บอะไรบ้าง: คำตอบ ตัวเลือกที่กด กล่องข้อความท้ายฟอร์ม ชื่อและช่องทางติดต่อถ้ากรอก รุ่นของระบบที่คุณตรวจ และเวลาที่เซิร์ฟเวอร์ได้รับ · ใช้ภายในทีมเพื่อแก้ผลิตภัณฑ์เท่านั้น ไม่เอาไปคิดคะแนนของใคร · หน้านี้ไม่มีคุกกี้ติดตาม ไม่มี Google Analytics และร่างคำตอบอยู่ในเบราว์เซอร์ของคุณเองจนกว่าจะกดส่ง

เรื่อง IP ขอพูดตรง ๆ ครับ: ตอนกดส่ง เซิร์ฟเวอร์เอาหมายเลข IP มาเป็นกุญแจนับว่าที่อยู่เดียวกันส่งมากี่ครั้ง ไว้กันคนยิงฟอร์มรัว ๆ อย่างเดียว — อยู่ในหน่วยความจำของโปรเซส ไม่ได้เขียนลงฐานข้อมูล ไม่ได้เก็บคู่กับคำตอบของคุณ นับเฉพาะช่วง 24 ชั่วโมงล่าสุด และหายทั้งหมดเมื่อเซิร์ฟเวอร์รีสตาร์ต · อีกสองอย่างที่ไม่ได้อยู่ในมือเรา คือ Google Cloud Run ที่เรารันอยู่เก็บ log ของตัวเองซึ่งมี IP ต้นทางติดไปด้วย และหน้านี้โหลดฟอนต์จาก Google ทำให้ IP ของคุณไปถึง Google ตั้งแต่ก่อนพิมพ์ตัวแรก · ที่ยืนยันได้คือคำตอบของคุณไม่ได้ถูกเก็บผูกกับ IP ของใคร · อ่านฉบับเต็มได้ที่ นโยบายความเป็นส่วนตัว

ส่งคำตอบกลับเอง

คำตอบทั้งหมดอยู่ในกล่องข้างล่าง — คัดลอกแล้ววางส่งกลับมาทาง LINE หรืออีเมลได้เลย

ถ้าปุ่มบันทึกไฟล์ไม่ทำงาน (บางแอปเปิดหน้าเว็บในตัวเองและกันการดาวน์โหลด) ให้ใช้ปุ่มคัดลอกแทนได้เลย ผลลัพธ์เหมือนกัน
