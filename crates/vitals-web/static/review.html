ตรวจ Vitals

เลือกก่อนว่าคุณตรวจในบทบาทไหน — คำถามจะเปลี่ยนตามบทบาท

อยากพูดมากกว่าพิมพ์: อัดเสียงส่งกลับมาทางเดิมที่ได้ลิงก์นี้มาได้เลยครับ (LINE หรืออีเมล) — ฟอร์มนี้รับไฟล์เสียงไม่ได้ จึงไม่ทำปุ่มอัปโหลดหลอกไว้ · จะกดตัวเลือกในข้อที่ตอบได้ก่อน แล้วอัดเสียงเฉพาะข้อที่อยากขยายความก็ได้

เก็บอะไรบ้าง: คำตอบ ตัวเลือกที่กด ชื่อและช่องทางติดต่อถ้ากรอก และเวลาที่ส่ง · ไม่เก็บ IP ไม่ติดตามการใช้งาน · ใช้ภายในทีมเพื่อแก้ผลิตภัณฑ์เท่านั้น

ส่งคำตอบกลับเอง

คำตอบทั้งหมดอยู่ในกล่องข้างล่าง — คัดลอกแล้ววางส่งกลับมาทาง LINE หรืออีเมลได้เลย

ถ้าปุ่มบันทึกไฟล์ไม่ทำงาน (บางแอปเปิดหน้าเว็บในตัวเองและกันการดาวน์โหลด) ให้ใช้ปุ่มคัดลอกแทนได้เลย ผลลัพธ์เหมือนกัน

ส่งแล้ว ขอบคุณมากครับ 🙏
